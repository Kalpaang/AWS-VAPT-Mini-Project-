# CVSS v3.1 Scoring Report

## 1. Objective

This report documents the Common Vulnerability Scoring System (CVSS) v3.1 scoring process used to assess the severity of vulnerabilities identified during the AWS VAPT mini project.

## 2. Scoring Methodology

The CVSS v3.1 calculator was used to determine the Base Score based on the vulnerability's attack characteristics and potential impact on confidentiality, integrity, and availability.

Official calculator: https://www.first.org/cvss/calculator/3.1

## 3. Example Calculation

The following score was generated while learning how to use the CVSS calculator. It is an illustrative example and is not a confirmed finding from the AWS assessment.

- CVSS Version: 3.1
- Example Base Score: 9.8
- Example Severity: Critical
- Example Vector: CVSS:3.1/AV:N/AC:L/PR:N/UI:N/S:U/C:H/I:H/A:H

## 4. Actual Assessment Findings

Actual vulnerabilities, CVSS vectors, Base Scores, severity ratings, and justifications will be documented here after assessment evidence has been reviewed.
